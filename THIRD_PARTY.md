# Сторонние материалы и зависимости

В T-01 внешние изображения, шрифты и данные ещё не добавлены. Прямые зависимости проекта:

| Пакет | Назначение | Лицензия |
|---|---|---|
| Phaser | Отрисовка игры | MIT |
| Preact | Интерфейс | MIT |
| Vite | Сборка клиента | MIT |
| TypeScript | Язык и проверка типов | Apache-2.0 |
| ESLint, @eslint/js, typescript-eslint | Линтер | MIT |
| Prettier | Форматирование | MIT |
| Vitest | Модульные тесты | MIT |
| happy-dom | DOM-окружение тестов интерфейса | MIT |
| Playwright | Проверка страницы в браузере | Apache-2.0 |

Версии прямых и транзитивных зависимостей зафиксированы в `pnpm-lock.yaml`. Их полные тексты лицензий доступны в пакетах после `pnpm install`.
