# Отчёт: веха M1 — Данные и карта

28 ноября 2026 · задачи: T-10…T-13 · PR: #6–#8, #10 · коммиты: `m0..m1`

## Коротко

Подготовлены игровые данные, береговая линия Средиземного моря, навигационная сетка 1 км и позиции пяти портов. Ядро читает настоящий бинарный файл карты и строит сетку 2 км для будущего поиска пути. Демо вехи — отладочная карта и проверка данных — пройдено локально; GitHub Actions по-прежнему не запускает задания из-за блокировки оплаты аккаунта.

## Как посмотреть

1. В корне репозитория выполнить `pnpm install`, затем `pnpm build`: команда проверит данные и соберёт ядро и клиент.
2. Открыть `packages/client/public/data/navgrid-debug.png`: синяя вода, бежевая суша, красные проливы и барьеры, жёлтые точки портов.
3. Выполнить `pnpm test`: тесты читают настоящий `navgrid.bin`, проверяют контрольные точки суши и моря, связность портов и разбор файла ядром.

Локально выполнены `pnpm data:build` в составе сборки, просмотр PNG и проверка портов и проливов тестами. Браузерный интерфейс карты относится к M4.

## Решения, принятые по ходу

- **T-10:** исходные данные отделены от географических дополнений; `data:build` объединяет их по идентификаторам. После появления карты отсутствие геоданных стало ошибкой.
- **T-11:** Natural Earth обрабатывает `mapshaper`; исходные архивы кэшируются вне Git и проверяются по SHA-256, а результат коммитится. Проекция общая для конвейера и ядра.
- **T-12:** маска сетки хранится по строкам, младший бит байта соответствует первой клетке; заголовок занимает 26 байт. Отладочное изображение уменьшено до шага 5 км на пиксель.
- **T-13:** клетка сетки 2 км считается водой при наличии воды хотя бы в одной исходной клетке, чтобы сохранить узкие проливы при поиске кандидата маршрута.

**Отступления от ТЗ:** зелёный CI не получен: GitHub Actions не запускает job `build` из-за блокировки оплаты аккаунта. По ранее принятому автором решению PR слиты после локальных проверок. Содержательных отступлений от карты и данных ТЗ нет.

## Изменённые файлы

- **core:** схемы данных, функции проекции, тип и загрузчик `NavGrid`; между задачами M1 добавлен также каркас ядра T-20.
- **client:** опубликованы `coast.json`, `navgrid.bin`, `navgrid-debug.png`, JSON с данными и линиями проливов.
- **tools:** `databuild` проверяет и объединяет данные; `mapgen` строит берег, сетку и позиции портов.
- **data:** исходные товары, порты, корабль, ветер и баланс; определения проливов и барьеров, сведения об источниках, сгенерированные координаты.
- **docs/config:** решения, прогресс, сведения о сторонних данных и настройки рабочих пакетов.

`git diff --stat m0..950ebb9`: 49 файлов, 5384 добавления и 65 удалений. Сводка включает T-20 (PR #9), слитую внутри периода. Добавлены зависимости `mapshaper` для инструментов карты и `zod` для проверки данных в `core`.

## Качество

Прошли `pnpm lint`, `pnpm typecheck`, `pnpm test` (36 тестов в 8 файлах) и `pnpm build`; новые тесты T-13 загрузили реальный файл карты. PR #7 и #8 проверили повторяемость конвейера карты. `navgrid.bin` занимает 1 776 765 байт, отладочная PNG — 12 777 байт. Клиентская сборка содержит JS 1,47 МБ (390,76 КБ gzip); Vite предупреждает о большом чанке. Производительность поиска пути пока не измерялась: поиск появится в T-24.

Известный риск: сетка 2 км может считать соседние водные клетки связанными через сушу. В T-24 маршрут следует проверять по сетке 1 км, а в T-23 использовать её же для движения. CI и артефакт `client-dist` остаются непроверенными из-за блокировки GitHub Actions.
