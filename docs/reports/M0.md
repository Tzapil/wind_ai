## Коротко

Создано pnpm-монорепо с чистым каркасом ядра и браузерным клиентом. Собранная страница показывает полноэкранный Phaser-канвас и русскую заглушку Preact; локальный шрифт загружается. Локальные проверки прошли. Зелёного CI и проверенного артефакта пока нет: GitHub не запускает задания из-за блокировки оплаты аккаунта.

## Как посмотреть

1. В корне репозитория выполнить `corepack enable`, `pnpm install`, `pnpm build`, `pnpm preview`.
2. Открыть адрес Vite (обычно `http://127.0.0.1:4173`). Проверить надпись «Попутного ветра» на синем фоне; холст должен занимать всё окно.
3. Для локальных проверок выполнить `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm e2e`. На Windows при блокировке `pnpm.ps1` использовать `pnpm.cmd`.

Демо вехи из ТЗ пройдено в Edge на собранной версии при 1280×720: заголовок и надпись русские, канвас 1280×720, PT Serif загружен. Проверка CI остаётся открытой по причине выше.

## Качество

Прошли `pnpm lint`, `pnpm typecheck`, `pnpm test` (11 модульных тестов в 3 файлах), `pnpm build`. Один E2E-тест подтвердил канвас и русскую заглушку; пробный JSX-литерал вызвал ошибку линтера. Production preview проверен в Edge, включая загрузку локального шрифта. Производительность не измерялась: игрового цикла ещё нет. Сборка: JS 1,47 МБ (390 КБ gzip), CSS 5,82 КБ, файлы шрифтов 688 КБ; Vite предупреждает о крупном JS-чанке Phaser. На этой Windows-машине Playwright иногда не завершает процесс сервера после успешного теста; сервер приходится останавливать вручную. Долг по CI и артефакту указан выше.
